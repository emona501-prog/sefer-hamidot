# ספר המידות — אפליקציית לימוד

אפליקציית לימוד לספר המידות של רבי נחמן מברסלב — קובץ HTML יחיד, עובד גם בלי אינטרנט.

- ביאור פשוט + הרחבה עם מקורות לכל הסימנים
- עוזר חכם (בוט) לחיפוש, פתיחת ערכים, הקראה וכמות סימנים
- כפתור "יש לך מקור?" לשיתוף מקורות בוואטסאפ
- עדכוני ביאורים מרכזיים מתוך `breslever-pro` (ענף `sefer-hamidot-data`)

קישור: https://emona501-prog.github.io/sefer-hamidot/
